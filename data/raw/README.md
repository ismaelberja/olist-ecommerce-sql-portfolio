# Original data (not tracked in Git)

Download the **Brazilian E-Commerce Public Dataset by Olist** from:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

Extract the original CSV files directly into this folder. The `olist_geolocation_dataset.csv` file is not needed for this analysis.
